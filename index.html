어떤 LLM이 제값을 할까

Artificial Analysis Intelligence Index에 오른 모든 모델을 API 혼합 단가와 함께 한 차트에 그렸습니다. 가성비 경계선 위의 모델은 이보다 싸면서 더 똑똑한 모델이 없는 모델이고, 나머지는 경계선 위의 어떤 모델에게 가격과 점수 모두에서 밀립니다. 기본값으로 모델마다 가장 점수가 높은 변형만 보여주고 점수가 낮은 모델은 숨깁니다. 더 넓게 보려면 필터를 조정하세요.

    가격 대비 성능

    예산별 최적 모델

    가성비 경계선을 표로 옮긴 것입니다. 예산이 속한 행을 찾으면, 그 가격대에서 가장 점수가 높은 모델이 추천 모델이고 같은 예산 안에서 그다음으로 좋은 모델이 차선입니다. 제조사를 선택하면 선택한 제조사 모델만으로 계산합니다.

    100만 토큰당 예산추천 모델점수가격차선

    순수 성능

    가격은 고려하지 않은 순위입니다.

    변경 내역

    데이터를 갱신할 때마다 이전과 비교한 결과입니다. 새로 추가되거나 제외된 모델, 점수나 가격이 바뀐 모델을 보여줍니다.

      전체 수치

      열 제목을 누르면 정렬됩니다. 모델 이름을 누르면 Artificial Analysis의 해당 모델 페이지로 이동합니다. 오른쪽으로 스크롤하면 세부 벤치마크 점수(%)가 있습니다.

      모델 제조사 출시일 종합 지능 코딩 수학 혼합 단가 $/1M 입력 $/1M 출력 $/1M 출력 속도 tok/s TTFT(초)

      읽는 법

      • 가성비 경계선. 가격이 낮은 순으로 정렬한 뒤, 자기보다 싼 모든 모델보다 점수가 높은 모델만 남긴 선입니다. 가격이 같으면 점수가 높은 쪽을, 점수가 같으면 싼 쪽을 남깁니다.
      • 혼합 단가는 Artificial Analysis가 입력:출력을 3:1로 섞어 계산한 100만 토큰당 가격입니다. 캐시 입력 할인, 배치 가격, 고속 모드는 반영하지 않습니다.
      • "모델별 대표만"을 켜면 같은 이름의 모델 중 effort·reasoning 변형에서 점수가 가장 높은 것만 남깁니다(점수가 같으면 싼 쪽). 끄면 AA가 따로 측정한 low, medium, high, xhigh, max effort 같은 변형이 모두 보입니다.
      • 사용 패턴은 내 사용량의 입력:출력 토큰 비율입니다. 비율을 바꾸면 (입력 단가×입력 비율 + 출력 단가×출력 비율) ÷ 비율 합으로 단가를 다시 계산하고, 가성비 경계선과 예산표도 그 단가로 다시 그립니다. 기본값 3:1은 AA 혼합 단가와 같습니다. 문서를 많이 넣고 짧게 답받는 RAG·요약은 입력 비중이, 코드·글 생성은 출력 비중이 큽니다.
      • 월 사용량을 넣으면(입력·출력 토큰, 100만 단위) 비율은 그 양에서 자동으로 계산되고, 차트 가로축·예산표·표가 입력 단가×입력량 + 출력 단가×출력량으로 계산한 월 예상 비용으로 바뀝니다. 월 비용은 단가에 총량을 곱한 값이라 경계선 위 모델은 같은 비율일 때와 같고, 단위만 "월 얼마"로 바뀝니다. 지우면 원래 비율 설정으로 돌아갑니다.
      • 세부 벤치마크는 AA가 측정한 개별 벤치마크의 정답률(%)입니다. 지표로 고르면 차트·예산표·순위가 그 점수로 바뀝니다. 모든 모델이 모든 벤치마크를 측정한 것은 아니어서, 점수가 없는 모델은 해당 지표에서 빠집니다. 특히 MMLU-Pro, LiveCodeBench, AIME 2025 등은 AA가 최신 모델에서 더 이상 측정하지 않아 "이전 측정"으로 분류되고, 고르면 경고가 표시됩니다(Math Index도 마찬가지). 분류는 데이터에서 상위 30개 모델의 점수 보유 여부로 자동 판단합니다.
      • "출시 시기"를 고르면 데이터 기준일로부터 그 기간 안에 출시된 모델만 차트와 경계선 계산에 넣습니다. 오래된 모델이 경계선을 차지하지 않게 하고, 지금 쓸 만한 모델끼리 비교할 때 씁니다.
      • "최소 점수"보다 낮은 모델은 차트와 경계선 계산에서 모두 빠집니다. 아주 싸고 오래된 소형 모델이 경계선의 시작점을 차지하지 않게 하기 위해서입니다.
      • 제조사는 최대 6곳까지 함께 선택할 수 있고, 제조사마다 색과 점 모양이 다릅니다. 채운 도형은 경계선 위, 빈 도형은 경계선 아래 모델입니다. 가성비 경계선은 항상 전체 모델 기준으로 그려서, 선택한 제조사가 전체 중 어디쯤 있는지 볼 수 있습니다.
      • 점수는 바뀝니다. AA는 버전이 바뀔 때 Index 기준을 다시 잡으므로, 예전 스냅샷과 비교하지 말고 이 페이지 안에서만 비교하세요.
